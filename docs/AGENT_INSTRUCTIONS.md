# Инструкция для Агентов и Разработчиков

Этот документ содержит описание проделанной работы по очистке проекта, а также инструкции по сборке и поддержанию чистоты в репозитории.

## Проделанная работа

1.  **Очистка проекта от мусора:**
    *   Был создан файл `.gitignore` для того, чтобы исключить из репозитория временные файлы, директории сборок и пользовательские настройки IDE. Это стандартная практика, которая помогает поддерживать репозиторий в чистоте и избегать конфликтов, связанных с файлами, специфичными для окружения разработчика.
    *   Были удалены следующие директории и файлы, которые являлись результатом сборки проекта или пользовательскими файлами, не предназначенными для хранения в системе контроля версий:
        *   `build_mvp/`
        *   `build-debug/`
        *   `build-debug-new/`
        *   `CMakeLists.txt.user`
        *   Резервные копии `CMakeLists.txt`

## Инструкции по сборке

Чтобы избежать добавления в репозиторий ненужных файлов, следуйте этим инструкциям:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    cd dsnote-qt6
    ```

2.  **Создайте директорию для сборки:**
    Рекомендуется создавать отдельную директорию для сборки проекта. Эта директория уже добавлена в `.gitignore`, поэтому ее содержимое не попадет в репозиторий.
    ```bash
    mkdir build
    cd build
    ```

3.  **Сконфигурируйте и соберите проект:**
    Используйте CMake для конфигурации и сборки проекта.
    ```bash
    cmake ..
    make
    ```

Следуя этим простым правилам, вы поможете поддерживать порядок в проекте.
